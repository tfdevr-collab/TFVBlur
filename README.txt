TFV BLUR website

Upload alle bestanden en de map assets naar de root van je GitHub-repository.
Zorg dat index.html direct in de root staat.
GitHub Pages: Settings > Pages > Deploy from a branch > main > /(root) > Save.

Aanpassen:
- Vervang hello@tfvblur.com in index.html door je eigen e-mailadres.
- Vervang voorbeeldproducten/teksten door je eigen collectie.
- Productkaarten zijn concepten; er is nog geen webshop of betaalsysteem.
